Execution Quick Reference

To activate a Hermes task: Message Hermes on Telegram with the skill command (eg, "/triage-notes"). For scheduled loops, configure on the Hetzner VPS cron.

To build a new skill: Use /writing-skills in Claude Code. Skills live in ~/.claude/skills/ or project .claude/skills/.

To schedule a recurring task: Use /schedule in Claude Code for remote agents, or /loop for session-scoped repeats.

To delegate to team: Write a runbook in Obsidian, share the relevant skill path, and assign the Linear issue.
